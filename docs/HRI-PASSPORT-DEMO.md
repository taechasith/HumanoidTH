# สคริปต์ Demo: HRI Passport

**"One Profile. Every Robot Understands You."**
*หุ่นยนต์ไม่ควรรอให้มนุษย์ปรับตัวเข้าหา หุ่นยนต์ควรเรียนรู้ที่จะปรับตัวเข้าหามนุษย์*

ความยาวประมาณ 5 นาที ใช้ผู้นำเสนอ 2 คน: **A** เป็นผู้บรรยาย และ **B** เป็นผู้ใช้ที่ยืนหน้าหุ่น

## ลำดับการนำเสนอ

### 0:00–0:40 ปัญหา
**A:** "หุ่นยนต์ในโรงพยาบาลไทยเริ่มเยอะขึ้น แต่ทุกตัวทำเหมือนกันกับทุกคน คือเดินเข้ามาใกล้ เร็ว จ้องตา และโบกมือ สำหรับผู้ป่วยที่กังวลหรือผู้สูงอายุ แบบนี้น่ากลัว แล้วเราก็ต้องบอกหุ่นทุกตัวซ้ำ ๆ ว่าเราชอบแบบไหน"

### 0:40–2:00 สร้าง Passport (Living Lab)
**B** ยืนหน้าจอ แล้ว **A** ติ๊ก consent และเลือก **ตอบด้วยเสียงหรือพิมพ์** (แนะนำ), **Start** (โหมดปุ่ม) หรือ **Auto** (โหมดกล้อง)

- โหมดเสียง: B กด **กดแล้วพูด** แล้วตอบทีละข้อ เช่น "สวัสดี", "ใกล้ไป", "กังวลนิดหน่อย" ถ้าเสียงรอบข้างดังหรือไมค์มีปัญหา ให้พิมพ์คำตอบหรือกดปุ่มแทนได้ทันที
- โหมดเสียงและโหมดปุ่มจะหยุดที่หน้า **ตรวจทานคำตอบก่อนบันทึก** ให้แก้ค่าให้ดู 1 ข้อ แล้วกดบันทึกหรือพูดว่า "บันทึก"

- หุ่นรอเงียบ ๆ ไม่จ้อง พอ **B ไหว้** หุ่นก็ไหว้ตอบพร้อมโค้ง
- หุ่นค่อย ๆ เข้าใกล้ทีละขั้น: กด **Continue** หรือในโหมด Auto ให้ B ยืนนิ่ง จากนั้น **B เอนตัวหนีหนึ่งครั้ง** หุ่นจะขอโทษและถอยออกไป
- ตอบคำถามเรื่องการสบตาและเสียงพูด (ในโหมด Auto ระบบวัดเองแล้วบันทึกอัตโนมัติใน 10 วินาที)

**A:** "แค่นี้ก็ได้ HRI Passport แล้วครับ ระยะห่าง ความเร็ว การสบตา ภาษา และความเร็วการพูด ทั้ง 5 อย่างอยู่ในพาสปอร์ตใบเดียว"

ชี้ไปที่การ์ดสีเขียวเข้ม: รหัส, QR, ป้าย *Active* และบรรทัด MRZ ด้านล่างแบบพาสปอร์ตจริง

### 2:00–2:40 สแกน QR ด้วยมือถือ
**B** สแกน QR บนจอ แล้วการ์ดก็เปิดบนมือถือทันที

**A:** "QR นี้คือลิงก์ที่มี token ลับยาว 256 บิต คนสแกนเห็นการ์ด ส่วนหุ่นยนต์อ่านลิงก์เดียวกันผ่าน API ข้อมูลอ่อนไหว เช่นความรู้สึกต่อหุ่นยนต์ จะไม่ถูกส่งให้หุ่นยนต์เลย หุ่นได้รับแค่ผลลัพธ์ เช่น 'ขยับช้าลง' และ 'ท่าทีสงบ'"

### 2:40–4:00 หุ่นยนต์หลายรุ่นใช้พาสปอร์ตเดียวกัน (Robot console)
สลับไปแท็บ `/living-lab/robot` วางลิงก์การ์ด แล้วกด **Read passport**

- **Robot A** (หุ่นเต็มตัว): หยุดที่ระยะที่ B เลือก ขยับช้าลง สบตาแบบเบา และไหว้ทักทาย
- **Robot B** (จอ telepresence ติดที่): ทำตามได้เท่าที่ฮาร์ดแวร์รองรับ และบอกตรง ๆ ว่าทำอะไรไม่ได้ เช่น "ไม่มีหัว จึงสบตาไม่ได้"
- **Default robot**: ไม่มีพาสปอร์ต จึงเข้าใกล้ เร็ว จ้องตา และโบกมือ

**A:** "ป้ายสีทอง ADAPTED คือสิ่งที่พาสปอร์ตเปลี่ยน เมื่อเทียบกับหุ่นที่ไม่มีพาสปอร์ต ข้อมูลชุดเดียว หุ่นต่างรุ่นแปลงไปใช้ตามความสามารถของตัวเอง นี่คือ 'One Profile. Every Robot Understands You.'"

ถ้ามีเวลา กด **Speak greeting** ให้หุ่นทักทายเป็นภาษาไทยด้วยความเร็วพูดที่ B เลือก

### 4:00–4:40 ผู้ใช้เป็นเจ้าของข้อมูล
กลับไปหน้า Card ในเครื่อง demo แล้วกด **Edit preferences** เปลี่ยนการสบตาเป็น "Direct" แล้วกด Save จะเห็น "Version 2"

กลับไปกด **Read passport** ในคอนโซลอีกครั้ง หุ่นทุกตัวจะได้ค่าใหม่ทันที

**A:** "ผู้ใช้แก้หรือลบพาสปอร์ตได้เองด้วย edit key ที่อยู่ในเครื่องของตัวเอง ถ้าลบ หุ่นทุกตัวก็จะอ่านไม่ได้อีก"

### 4:40–5:00 ปิด
**A:** "หุ่นยนต์ในเดโมนี้เป็น **การจำลองบนเบราว์เซอร์** ยังไม่ได้ควบคุมหุ่นจริง แต่ API ที่หุ่นจริงจะใช้พร้อมแล้ว มีเอกสาร มีการป้องกันการเดา token และมี rate limit หุ่นจริงตัวไหนอ่าน JSON ได้ ก็ต่อเข้ามาได้เลย"

## คำถามที่กรรมการน่าจะถาม

| คำถาม | คำตอบ |
|---|---|
| ควบคุมหุ่นจริงได้ไหม | ยังไม่ได้ ทุกอย่างเป็น three.js ในเบราว์เซอร์ (มีป้ายบอกในหน้า) แต่ API คือสัญญาที่หุ่นจริงจะใช้ ดู `docs/hri-passport-api.md` |
| ระยะห่างเป็นเมตรไหม | ยังไม่ใช่ ระบบเก็บเป็นหน่วยของฉาก 3D และ API ส่ง `metres: null` ไปตรง ๆ หุ่นแต่ละรุ่นใช้ `band` (ใกล้ / กลาง / ไกล) หรือ `closeness` (0–1) แปลงเป็นระยะจริงที่ปลอดภัยของตัวเอง เราไม่สร้างตัวเลขเมตรขึ้นมาเอง |
| ข้อมูลส่วนตัวปลอดภัยไหม | ต้องได้ consent ก่อนเริ่ม, ภาพจากกล้องประมวลผลในเครื่องเท่านั้น, token เก็บเป็น hash, API ไม่ส่งชื่อเล่น ความกังวล หรือ log, ลบได้ทันที, และไม่เก็บ IP จริง |
| ถ้ามีคนเดา token ล่ะ | token มี 256 บิต และถ้าค้นผิดเกิน 20 ครั้งใน 10 นาที ระบบจะบล็อกผู้เรียกคนนั้น รวมถึงการเดารหัส 6 ตัวด้วย |
| โหมด Auto อ่านอารมณ์จากหน้าไหม | ไม่อ่าน เราดูแค่ภาษากาย คือการไหว้ การเอนหนี การเอนเข้า และการหันหน้า ไม่เดาความรู้สึกจากใบหน้า |
| แม่นแค่ไหน | ตรรกะผ่าน unit test ครบ แต่ความแม่นยำกับคนจริงยังต้องวัดตามแผนทดสอบใน `HRI_FEASIBILITY_SPIKE.md` §3.4 (ตอบตามจริง) |

## แผนสำรอง

| ถ้าเกิด… | ให้ทำ… |
|---|---|
| กล้องไม่ติด หรือโหมด Auto อ่านค่าผิด | กด "Stop and use buttons instead" แล้วทำต่อด้วยโหมดปุ่ม |
| หุ่น 3D ไม่ขึ้น (WebGL) | ใช้แท็บ passport สำรองที่เปิดไว้ แล้วเล่าเฉพาะส่วน API และ Card |
| ไม่มีเสียงไทย | ปิดเสียง ทุกขั้นตอนมีข้อความบนจออยู่แล้ว |
| มือถือสแกน QR ไม่ได้ (เน็ตคนละวง) | คัดลอกลิงก์จากปุ่ม "Copy link" ไปวางในคอนโซลหุ่นยนต์แทน |
| ขึ้นข้อความ "Too many requests" | เกิดจาก rate limit รอ 1 นาที หรือใช้ passport สำรอง |
